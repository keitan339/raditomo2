# 技術要件定義

## システム構成

本システムは以下の2つのコンポーネントと共通基盤で構成される。

### C1: Webアプリ（SPA）

- ダウンロード登録（F1）と録音ファイルの再生（F3）を1つのSPAに統合する
- メニューで番組表・登録一覧・再生・履歴・設定を切り替える
- ラジコの番組表をWebアプリとして表示する
- ユーザーが録音したい番組を選択し、ダウンロード対象として登録する
- ダウンロード済みの録音ファイルをHLS形式でストリーミング再生する
- ダウンロード状況の確認画面を含む（失敗・期限切れ件数のバッジ表示）
- Web画面からF4（番組表取得）・F2（ダウンロード）を手動実行できる（非同期実行）
- iOS / Androidネイティブアプリ（React Native）は将来対応

### C2: バッチ処理

- Spring Schedulerにより毎日定時に自動実行される
- CLI形式での手動実行にも対応する
- 以下の2つのバッチ処理を含む（番組表取得完了後にダウンロードを実行する）
  - **番組表取得バッチ**: ラジコから対象エリアの番組表を取得しDBに保存する
  - **タイムフリーダウンロードバッチ**: ダウンロード登録されている番組をラジコからダウンロードしMP3形式で保存する。ダウンロード後にffmpegでHLSセグメントに事前変換する

### 共通基盤: バックエンドAPI / データベース

- ダウンロード登録データ・録音ファイルの管理を行うAPIサーバー
- 認証機能を提供する（Google OAuth 2.0 + JWT）
- ダウンロード失敗・期限切れ時のメール通知機能（Gmail SMTP経由）
- C1, C2 が共通で利用する

## インフラ

- **初期**: 自宅サーバーで稼働
- **将来**: AWS へ移行予定
- コンテナ化（Docker）しておくと移行が容易

## 非機能要件

### 対応ブラウザ

- PC・スマホのモダンブラウザ（Chrome・Safari）を対応対象とする
- レスポンシブデザインとし、スマホでも操作可能なUIとする

### セキュリティ

- 認証機能を設け、認証済みユーザーのみアクセス可能とする
- スマホからのアクセスを想定し、外部公開に耐えるセキュリティを確保する
- HTTPS必須：NginxでSSL/TLS終端を行う（Let's Encryptで証明書を取得）

### Webサーバー構成

- Nginxをリバースプロキシとして配置する
  - HTTPS終端（SSL/TLS）
  - Reactビルド済み静的ファイルの配信
  - Spring Boot APIへのリクエストプロキシ（/api/*）
  - HLSストリーミングファイルの配信

### ログ

- Spring Bootの標準ログ機能を使用し、ファイルに出力する
- バッチ処理（F2・F4）の実行結果・エラー詳細はログで確認できるようにする

### コンテナ構成

- Docker Composeで以下の3コンテナを構成する
  - **Nginx**: リバースプロキシ、SSL終端、React静的ファイル配信、HLSファイル配信
  - **App（Spring Boot）**: バックエンドAPI + バッチ処理（スケジューラー・CLI）を同一コンテナで稼働
  - **DB（PostgreSQL）**: データベース
- 全コンテナのタイムゾーンをJST（Asia/Tokyo）に設定する
- 録音ファイル（MP3・HLS）と生XMLはホストのボリュームにマウントして永続化する
- 自宅サーバーからAWSへの移行を容易にするため、環境依存の設定は環境変数で管理する

### 外部システム連携

- **ラジコ（radiko）API**
  - 番組表XML取得（エリア・放送局・日付を指定）
  - タイムフリー音声ストリームの取得（2026年1月の仕様変更により、`smartstream.ne.jp` 経由のチャンク分割取得方式）
  - デバイスレベルの認証トークン方式（auth1/auth2）で認証する（アカウント登録不要）
  - 参考実装: [rec_radiko_ts](https://github.com/uru2/rec_radiko_ts)（仕様変更対応済みのOSSツール）
- **Google OAuth 2.0**
  - ユーザー認証に使用（ログイン・ログアウト）
  - 許可リストに登録されたGoogleアカウントのみアクセスを許可する
- **Gmail SMTP**
  - ダウンロード失敗・期限切れ・番組表取得エラーの通知メール送信に使用
  - 通知先はログインしたGoogleアカウントのメールアドレス
